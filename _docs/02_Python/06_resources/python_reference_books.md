# Python — reference books for professional-level learning

Reading order relative to where I am in the 42 Python modules (module 02 as of 2026-07-15).

## The foundation (now)

- **Python Distilled** — David Beazley. Concise and modern, covers the core language without the fluff. Good to consolidate the basics properly.
- **Effective Python** (2nd ed.) — Brett Slatkin. ~90 short items in the form "do this, not that, and here is why". Very digestible right after the 42 modules.

## The essential reference (in a few months)

- **Fluent Python** (2nd ed.) — Luciano Ramalho. *The* book for the Python data model: dunder methods, iterators, decorators, typing, concurrency. Dense — read once comfortable with the basics. Universally cited as the level-up book.

## Professional engineering side

- **Robust Python** — Patrick Viafore. Typing, contracts, maintainable code in a team.
- **Architecture Patterns with Python** — Percival & Gregory. Architecture, DDD, tests. Free online: <https://www.cosmicpython.com>
- **Python Testing with pytest** (2nd ed.) — Brian Okken. Serious testing = pytest.

## Under the hood (later)

- **Python Cookbook** (3rd ed.) — Beazley & Jones. Idiomatic recipes; aging a bit but still solid.
- **CPython Internals** — Anthony Shaw. How the interpreter actually works.

## If buying only two

1. **Effective Python** — now.
2. **Fluent Python** — in a few months.

Also: the [official docs](https://docs.python.org/3/) are unusually good — the tutorial and the HOWTOs are worth as much as some books.
